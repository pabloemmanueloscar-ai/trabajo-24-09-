# Mercadito Feria

Página web estática que presenta ofertas de productos de almacén. Está hecha con HTML y CSS, y se adapta a móvil, tablet y escritorio.

## Cómo ver el sitio

Abre `index.html` en un navegador. No hace falta instalar dependencias ni iniciar un servidor.

## Productos

- Azúcar: $1500
- Aceite: $4000
- Mermelada: $2000
- Harina: $900

## Archivos

- `index.html`: estructura y contenido de la página.
- `estilo.css`: estilos y diseño adaptable.
- `aceite.webp`, `azucar.jpg`, `harina.jpg` y `mermelada.jpg`: imágenes de productos.
- Archivos `Responsive`: mockups de referencia para escritorio, tablet y celular.
